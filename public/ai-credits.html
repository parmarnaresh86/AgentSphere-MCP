How cost is calculated

Cost per call = input tokens ÷ 1,000,000 × input price + output tokens ÷ 1,000,000 × output price. A model id returned by the provider is matched exactly first, then by the longest prefix (e.g. gpt-4o prices gpt-4o-2024-08-06), then falls back to the Default (*) row. Rates are snapshotted onto each usage row, so changing a price never rewrites past history.
