1 Introduction & Overview

AgentSphere AI is an AI assistant for SAP Business One. Your team can query live SAP data, create documents through guided agents and run analytics by typing plain-language questions. Nobody needs to know SAP menus.

ℹ️ Your screens may look slightly different An administrator can rebrand the product name, logos, company name and "Powered by" credit. They can also switch between the HANA and Fiori themes (see Company Setup). The menu also changes with your role: you only see the items your role allows.
💬

Natural Language Chat

Ask in plain English, by voice or with an attached document. Common questions are answered instantly without using AI credits.

🔄

Guided Document Agents

Step-by-step agents for the full P2P and O2C chains: PR → PO → GRPO → AP Invoice → Payment, and Quotation → Order → Delivery → AR Invoice → Receipt.

🤖

40+ AI Agents

Live Analytics

Financial reports, sales and purchase analysis, aging and dashboards built on live SAP B1 / HANA data.

Multi-Company

Switch between SAP B1 company databases from the top bar.

2 System Requirements & Installation

Prerequisites

  • Windows server with Administrator rights for installation. The app runs as a Windows Service.
  • Node.js 20 LTS or newer (22 or 24 recommended). The bundled SQLite driver does not support Node 18.
  • Network access to your SAP B1 Service Layer, normally HTTPS on port 50000 (https://<server>:50000/b1s/v1).
  • Optional: direct access to the SAP HANA (port 30015) or MSSQL (port 1433) database, for DB SQL / Analytics V2 and batch/serial/bin picking.
  • A modern browser (Chrome, Edge or Firefox).
  • Optional AI provider: Anthropic Claude (direct), Azure OpenAI GPT-4o, or Claude on Azure AI Services. Without a key, the app runs in Standard (rule-based) mode.

Installation (recommended)

Right-click install.bat and choose Run as administrator. The one-touch installer then does the following:

  1. Checks the Node.js version, runs npm install, then runs npm run build.
  2. Asks for your SAP Service Layer URL, company DB, user and password and an AI provider, then writes the .env file. It generates a DB_ENCRYPT_KEY and can optionally test the SAP login.
  3. Registers the Windows Service "AgentSphere AI" (starts at boot) and adds a firewall rule "AgentSphere AI (port 3000)".
  4. Creates desktop shortcuts AgentSphere AI - Start / Stop / Status.
  5. Creates the local database (hanny.db) with the default login admin / admin123.
  6. Optionally installs the Claude Desktop MCP connector and the ChatGPT SQL Gateway connector.
  7. Opens http://localhost:3000 and prints the LAN URLs (http://<server-ip>:3000).
⚠️ Change the default passwords A new install creates the accounts admin and superadmin, both with password admin123. Change or replace them before going live. There is no in-app password change yet: create new accounts under User Management.

Manual alternative (developers): npm install → npm run build → create .env → npm run chat.

Login Process

  1. Enter your Username. Usernames are not case-sensitive. The login uses a username, not an email address.
  2. Enter your Password. Click the eye icon to show or hide it.
  3. Click Sign In. The button shows "Signing in…" and then "Welcome, name! Redirecting…".
  4. You land on the AI Chat screen in the HANA theme, or on the My Home launchpad in the Fiori theme.
ℹ️ Session length A login session lasts 12 hours from sign-in, whether or not you are active. After that you are sent back to the login page; some agent screens show "Session expired — please refresh the page" instead. Click the red Logout button in the top bar to end your session early.
⚠️ Forgotten password There is no self-service password reset. Ask your administrator. They manage accounts under Admin → User Management and can delete the account and create it again with a new password.

5.0 How the Copy-From Agents Work

All the document-conversion agents use the same four-step flow. On the P2P side these are PO → GRPO, GRPO → AP Inv and AP Inv → Credit; on the O2C side, Quot → Order, Order → Delivery, Delivery → AR Inv and AR Inv → Credit. Every agent screen has a white header with Back and a step badge, a step bar, and a welcome card that says "AI Guided Workflow".

  1. Pick the vendor / customer. Use the dropdown or filter and click Select →. Only parties with open source documents appear, each with an "(N open)" count.
  2. Pick one source document. The table shows Doc # / Date / Due / Reference / Total. Click Select →. Only open documents can be selected.
  3. Review the lines. Edit quantities and, where allowed, price, Disc%, tax code and warehouse. Then click ✅ Post <document>. Use ← Change <source> to go back.
  4. Done. A success card "✅ <document> Created Successfully" appears, with a 🖨️ Print link.
💡 Typing a document number You can type the source document number instead of clicking, for example 716, #716, SO 716 or GRPO 716. Hyphenated forms such as SO-716 are treated as a name search, so leave out the hyphen.

How to create a Purchase Request

  1. Choose Existing Item or New Item. A new item code is added to the Item Master automatically when the PR is posted.
  2. Pick the item from the list or search for it. The agent shows a 📦 Inventory Analysis (On Stock, Committed, On Order, Available, Reorder Level, Suggested Order Qty).
  3. Enter the quantity, or click the suggested-quantity chip. Then pick a warehouse, or Skip.
  4. Click Add Another Item to repeat, or Proceed to Header.
  5. Optionally pick a vendor ("Use <default vendor>" or Skip).
  6. Set the required date with the +7 days or +14 days chips, or type YYYY-MM-DD / DD-MM-YYYY. The date must be in the future; phrases like "next Friday" are not accepted.
  7. Add a comment or skip it, review the summary, then click ✅ Yes, Post to SAP.
  8. The result shows "✅ Purchase Request Created!" with the Document # and a 🖨️ Print Requisition link.

5.2 Purchase Order Agent

Purchase — P2P → AI Workflow → Purchase Order builds a new Purchase Order from scratch, without a PR. A PO Builder panel shows the order as you go. For a quick form instead of a guided agent, use Quick Create → Purchase Order.

5.3 PR → PO

Open Purchase — P2P → AI Workflow → PR → PO. The agent opens with a 📊 Pending PRs by Vendor table (Vendor, Code, PRs, Oldest, Overdue) and a checklist of open PRs.

  1. Tick one or more PRs. Use "Filter PRs by number or vendor…" to narrow the list, and 👁 View to open a PR's details.
  2. Click ✅ Proceed with N PR(s) →. All selected PRs are merged into one Purchase Order.
  3. Confirm the vendor. If the PRs have different vendors or none, the agent asks you to choose one, or you can pick Skip (Open Order). Then set the required date and comments.
  4. Fill in any missing Price or Whs in the PO Builder panel. Lines without a price are flagged.
  5. Click ✅ Yes, Post PO to SAP. The result "✅ Purchase Order Created!" lists the source PRs and has a 🖨️ Print PO link. The PO lines are linked to the PRs, so the PRs close.
ℹ️ Need separate POs?Run the agent once per vendor and select only that vendor's PRs. Reload PRs in the header refreshes the list.

5.4 PO → GRPO

Open Purchase — P2P → AI Workflow → PO → GRPO. It follows the copy-from flow in 5.0: Vendor › Purchase Order › Review Lines › Posted.

  • Header: Posting Date, Delivery Date, Vendor Ref / Delivery Note, Remarks.
  • Lines: Recv Qty, Unit Price, Disc%, Tax and Whse can all be edited.
  • 🏷️ Create Batches / 🔢 Create Serials appear for batch- or serial-managed items. 📍 Select Bins appears for bin-enabled warehouses.
  • + Add Line adds a substitute or extra item. It is posted without a PO link.
  • Click ✅ Post Goods Receipt PO.
💡 Partial receiptsEnter a lower Recv Qty. The PO stays open for the remaining quantity.

5.5 GRPO → AP Inv

Open Purchase — P2P → AI Workflow → GRPO → AP Inv. It follows the copy-from flow: Vendor → open GRPO → review invoice lines → post A/P invoice.

  • Header: Vendor Invoice No., and Due Date (leave it blank to use the payment terms).
  • Lines: Invoice Qty, Price, Disc% and Tax can be edited. The warehouse is locked, and no batch or serial entry is needed.
  • + Add Line adds extra items or services, such as freight. Batch- or serial-managed items cannot be added this way.
  • Click ✅ Post A/P Invoice.
ℹ️ Checking or scanning the supplier's invoice?This agent does not compare against the supplier's invoice. Use Three-Way AP Invoice to enter the invoice and match it, or Scan A/P Invoice to read it by OCR.

5.7 Scan A/P Invoice (OCR)

Open AI Agents → OCR Processing → Scan A/P Invoice. It reads a supplier invoice with AI vision OCR and matches it to a GRPO.

  1. Select the GRPO.
  2. Upload the invoice ("Drop supplier invoice here or click to browse"). PDF, JPG, PNG and WEBP up to 15 MB are accepted.
  3. Review the match. Each line is marked matched, qty mismatch, price variance, not invoiced or invoice only. The 🧾 Invoice Summary panel shows the totals.

Check that the SAP Service Layer is running and that port 50000 is open.
SSL / certificate errorSelf-signed Service Layer certificateMake sure NODE_TLS_REJECT_UNAUTHORIZED=0 is in .env (the installer sets it), then restart.
"Session expired — please refresh the page", or sent back to loginYour 12-hour app session endedRefresh and sign in again. Expired SAP sessions are renewed automatically.
"Invalid username or password"Wrong credentials, or no accountAsk an administrator to check or create your account under Admin → User Management.
"Network error — server unreachable" on loginThe server is not running, or the network or firewall is blocking itRun Status.bat or diagnose.bat on the server. Check the firewall rule for port 3000.
A menu item is missingYour role doesn't include itAsk an administrator to add it under Roles & Permissions or User Rights. Then log in again.
"AI credit limit reached — you have used $X of your $Y allowance…"Your AI allowance is used upAn administrator adds credit under AI Credits & Usage → User Credits → ＋ Add credit. Meanwhile, use the Standard engine.
"AI access is blocked for your account"Blocked by an administratorAdministrator: AI Credits & Usage → ✅ Unblock AI access.
AI not responding / slowMissing or invalid AI key, rate limit, or DEMO_MODE=trueCheck AI_PROVIDER and the matching key in .env (ANTHROPIC_API_KEY or AZURE_OPENAI_API_KEY + endpoint). Restart the service after changing .env.
"I didn't understand that. Type help…"Standard mode didn't recognise the questionRephrase with document numbers, codes or dates, type help, or switch to an AI engine.
"No database connected. Activate a DB connection…"DB SQL / Analytics V2 / Query Builder / batch picking needs a direct DB connectionSet one up under Tools → Developer Tools → DB Connection, or add HANA details to the SAP connection.
Document posting failsAn SAP business rule (stock, credit limit, mandatory UDF, closed period, …)Read the error message shown on the agent's review step, correct the lines, and post again.
Server won't startPort 3000 is in use, Node.js is missing or too old, or the service is brokenRun diagnose.bat and follow its ACTION PLAN. Check node --version (20 or later). Try fix-service.bat.
