1 Introduction & Overview

Agentsphere AI is an intelligent conversational assistant built specifically for SAP Business One. It gives your team the ability to query live SAP data, create business documents, and run complex workflows — all through plain English conversation, without needing to know SAP menus or transaction codes.

💬

Ask questions in plain English. The AI understands intent and fetches live SAP data automatically.

🔄

2 System Requirements & Installation

Prerequisites

  • Node.js version 18 or higher
  • Network access to your SAP B1 Service Layer (HTTPS on port 50001 typically)
  • A modern web browser (Chrome 90+, Firefox 90+, Edge 90+)
  • An AI provider API key: Anthropic Claude, Azure OpenAI, or Azure GPT-4o

Installation Steps

  1. Install dependencies — Run install.bat (Windows) or npm install in the project root.
  2. Configure environment — Copy .env.example to .env and fill in your SAP B1 Service Layer URL, company database name, credentials, and AI API key.
  3. Build the MCP server — Run npm run build to compile TypeScript to dist/.
  4. Start the application — Run Start.bat or npm run chat. The web UI starts on port 3000.
  5. Open in browser — Navigate to http://localhost:3000 (or your server IP).

How to Create a Purchase Request

  1. Navigate to Purchase (P2P) → Purchase Request Agent in the sidebar.
  2. Describe what you need: "I need 50 units of item A0001 from vendor V10000 by next Friday"
  3. The agent will confirm each detail and show a live summary on the right side panel.
  4. Add more items if needed: "Also add 10 units of B0025"
  5. Type "Confirm" or "Create PR" to submit the purchase request to SAP B1.
  6. The system returns a PR Document Number confirming creation.

5.3 PO → Goods Receipt (GRPO)

When goods arrive, use this agent to receive against open Purchase Orders and create Goods Receipt POs (GRPOs).

  1. Navigate to PO → GRPO. The agent lists all open POs ready to receive.
  2. Select the PO: "Receive PO-2201"
  3. The agent shows each line item and asks for received quantity.
  4. Confirm partial or full receipt: "Full receipt" or "Received 40 out of 50"
  5. The agent creates the GRPO in SAP B1 and returns the document number.
💡 Partial Receipts You can receive a partial quantity against a PO line. The PO remains open for the remaining quantity until a final receipt is posted.

5.5 GRPO → AP Invoice

This agent matches Goods Receipts to vendor invoices — with optional OCR support for uploading PDF invoices.

  1. Navigate to GRPO → AP Invoice.
  2. The agent lists GRPOs awaiting invoicing from each vendor.
  3. Optionally upload a PDF invoice for OCR extraction: drag & drop or click the attach button.
  4. Review extracted amounts — the system cross-references PO prices and flags discrepancies.
  5. Confirm to create the AP Invoice in SAP B1.
ℹ️ OCR Invoice Processing PDF invoices are parsed using the built-in PDF extractor. The agent identifies line items, unit prices, and totals automatically. You review and confirm before posting.

6.2 Quotation → Sales Order

When a quotation is accepted, convert it to a Sales Order in one step.

  1. Navigate to Quot → Order. Open quotations are listed by customer.
  2. Select the quotation: "Convert quotation SQ-405 to sales order"
  3. Confirm any final changes (quantity adjustments, delivery date).
  4. The system creates the Sales Order and returns the SO document number.

6.3 Order → Delivery Note

Generate Delivery Notes from confirmed Sales Orders for warehouse dispatch.

  1. Navigate to Order → Delivery. Open orders ready to ship are listed.
  2. Select one or more orders: "Create delivery for SO-1088"
  3. Specify warehouse and shipping details if prompted.
  4. Confirm — the Delivery Note is created in SAP B1.

6.4 Delivery → AR Invoice

Invoice customers directly from posted Delivery Notes.

  1. Navigate to Delivery → AR Invoice.
  2. Select the delivery: "Invoice delivery DN-804"
  3. Review the invoice amounts and payment terms.
  4. Confirm to post the AR Invoice in SAP B1.

6.6 AR Credit Memos

Using the Query Builder

  1. Select a database connection from the connection dropdown (top right).
  2. Browse the Schema Browser (left panel) to explore tables and columns. Click a column name to insert it into the editor.
  3. Write your SQL query in the dark editor panel. Standard SQL syntax for MSSQL or HANA is supported.
  4. Click ▶ Run Query or press Ctrl+Enter to execute.
  5. Results appear in the bottom panel as a formatted table.
  6. Click 📋 Save to cache the query for future use.
ℹ️ AI-Assisted Query Generation Type a plain English question in the chat box below the editor and click Generate SQL. The AI will write the query for you based on the connected schema.

10 Master Data Agent

The Master Data Agent allows you to create and update Customers, Vendors, and Items in SAP B1 through natural conversation. Navigate to Master Data & Analytics → Master Data Agent.

Creating a New Customer

12 Tips & Best Practices

Natural Language Query Tips

  • Be specific about dates: Say "this month", "last quarter", "January 2026", or "last 30 days". The system always uses the current date as context.
  • Reference document numbers directly: "Show me SO-1088" or "What's the status of PO-2201?"
  • Use customer/vendor codes or names: Both work — "C20000" and "Maxi-Teq" are equivalent.
  • Ask for follow-ups: After a result, ask "Now break that down by item group" or "Show me the same for last year".
  • Use action words for document creation: "Create", "Generate", "Make", "Add" trigger document creation agents.

Performance Tips

  • The NLP layer handles common queries (stock levels, sales totals, AR/AP aging) instantly without AI — these responses are faster than open-ended questions.
  • For large datasets (e.g., all transactions for a full year), use the DB Query Builder for faster direct SQL execution.
  • Use the Forecasting Agent weekly to keep demand predictions fresh.

13 Troubleshooting

ProblemLikely CauseSolution
Cannot connect to SAP B1 Service Layer URL wrong or service down Check SAP_B1_SERVICE_LAYER_URL in .env. Verify SAP B1 service is running. Check firewall rules on port 50000.
SSL certificate error on startup Self-signed SAP Service Layer certificate Set NODE_TLS_REJECT_UNAUTHORIZED=0 in .env. This is expected for on-premise SAP installs.
"Session expired" error SAP B1SESSION cookie expired The system auto-renews sessions on 401 errors. If it persists, check SAP B1 credentials in .env.
AI not responding / slow API key invalid or rate limited Verify ANTHROPIC_API_KEY (or Azure key) in .env. Check your API usage dashboard.
"I didn't understand" response Query too vague or intent not recognized Be more specific. Try using exact document numbers, customer codes, or dates. Type "help" to see example queries.
Login fails User account not set up Ask your administrator to create your user account via the Roles & Permissions page.
Document creation fails Missing required SAP fields or business rule violation Read the error message — the AI translates SAP errors to plain English. Common issues: item not in warehouse, credit limit exceeded, mandatory UDF missing.
Server won't start Port 3000 already in use or Node.js not installed Run Status.bat to check if already running. Ensure Node.js ≥18 is installed: node --version.
